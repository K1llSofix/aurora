# Aurora Launcher

Лаунчер Minecraft, который ставит и запускает игру вместе с клиентом [Aurora](../README.md): Minecraft 26.3, Fabric, Fabric API и мод Aurora ставятся одной кнопкой «Играть». Окно без рамки в стиле мода: стекло, тёмно-синие тона и бирюзово-фиолетовые акценты. На фоне — та же живая сцена с северным сиянием над горным озером, что и в главном меню Aurora в игре.

## Что умеет

- **Установка в один клик.** Скачивает версию игры, библиотеки, ресурсы и Java 25 от Mojang (свою Java ставить не нужно), Fabric Loader и свежий Fabric API, кладёт мод Aurora. Каждый файл проверяется по SHA-1, загрузка идёт в 16 потоков с докачкой при обрыве. Прогресс, скорость и оставшееся время видны на кнопке и в нижней панели. Повторный запуск проверяет файлы за секунду и не качает лишнего. Aurora обновляется сам: лаунчер раз в час и перед каждым запуском смотрит версии мода на [Modrinth](https://modrinth.com/mod/L7X9iCgB) и ставит более новую, чем встроенная: проверяет SHA-1 и то, что внутри действительно Aurora. Так же появляется поддержка новых версий Minecraft: достаточно выложить сборку мода под них. Без интернета или пока проект не выложен используется встроенная сборка.
- **Аккаунты.** Офлайн-ники (с той же головой скина, которую покажет игра) и Microsoft: вход через браузер по короткому коду, пароль лаунчер не видит. Токены зашифрованы средствами Windows (DPAPI) и сами обновляются перед запуском. В игре по-прежнему работает переключатель аккаунтов Aurora, а при запуске из лаунчера выигрывает аккаунт, выбранный в лаунчере.
- **Серверы.** Живой список: иконки серверов, цветные MOTD, онлайн и пинг (тот же запрос статуса, что и в «Сетевой игре»). Кнопка «Играть» запускает игру сразу на выбранном сервере. Можно добавлять и удалять свои серверы.
- **Модпаки.** Вкладка «Модпаки» на странице «Моды» ищет модпаки для Fabric в каталоге Modrinth. Модпак ставится отдельной установкой со своей папкой: в диалоге выбирается версия (с поиском по номеру или версии Minecraft) и название, а для версий, которые поддерживает Aurora, мод можно добавить одним переключателем. Лаунчер скачивает файлы модпака с проверкой SHA-1, копирует его настройки (`overrides`, затем `client-overrides`) и закрепляет нужную версию Fabric Loader, иконка модпака становится иконкой установки. Свой файл `.mrpack` ставится карточкой «Установить модпак» на странице «Установки» или перетаскиванием на неё. Модпаки для Forge, NeoForge и Quilt лаунчер честно отклоняет, а пути за пределы папки установки и загрузки с сайтов вне списка формата (cdn.modrinth.com, GitHub, GitLab) не пропускает.
- **Моды, ресурспаки и шейдеры.** На странице «Моды» три вкладки. Моды: список с иконками и описаниями из `fabric.mod.json`, включение и выключение, удаление в корзину, перетаскивание `.jar` в окно. Ресурспаки: включение прямо из лаунчера (они попадают в `options.txt` в нужном порядке), перетаскивание `.zip`. Шейдеры: выбор активного шейдера одним кликом, а если Iris ещё нет, лаунчер предложит поставить его вместе с Sodium. Каталог [Modrinth](https://modrinth.com) в каждой вкладке показывает только то, что подходит к версии установки, ставит моды с обязательными зависимостями и сразу включает скачанный ресурспак или шейдер.
- **Ярлыки как в PrismLauncher.** В меню карточки установки есть «Ярлык на рабочем столе» и «Добавить в меню «Пуск»». Ярлык запускает игру сразу, без окна лаунчера: появляется только маленькая заставка с прогрессом проверки файлов, а после выхода из игры всё закрывается само. Если игра не запустилась, заставка покажет причину и кнопку «Открыть лаунчер».
- **Иконки установок.** У каждой установки своя иконка: значок Aurora, цветные плитки, текстуры из самой игры (трава, алмаз, меч, крипер, ТНТ и другие) или любая своя картинка. Та же иконка ставится на ярлык и обновляется на нём при смене.
- **Скин офлайн-аккаунта.** Кнопка с палитрой у офлайн-аккаунта открывает редактор: живая 3D-модель, на которой можно рисовать прямо мышью, и развёртка 64×64. Есть карандаш, ластик, заливка грани, пипетка, отмена и повтор, внешний слой, модели Classic и Slim. Скин можно загрузить файлом, выбрать в каталоге MineSkin или взять у любого лицензионного игрока по нику. Игра с модом Aurora показывает этот скин на вашем персонаже.
- **Установки.** Несколько установок с отдельными папками (миры, моды, настройки): любая версия Minecraft, Fabric или ванилла, своя память, размер окна, папка игры и аргументы JVM. Aurora включается только там, где мод поддерживает версию.
- **Запуск и вылеты.** Пока идёт игра, лаунчер прячется в трей и возвращается после выхода (поведение настраивается). Встроенная консоль показывает лог игры с подсветкой предупреждений и ошибок. Если игра вылетела, лаунчер покажет последние строки лога и откроет отчёт о краше.
- **Статус в Discord.** Пока открыт лаунчер, друзья видят в Discord «В лаунчере Aurora». Ванильная установка или установка без Aurora показывается как «Minecraft <версия>», а в игре с Aurora статус ведёт сам мод, подробнее. Под статусом есть кнопка «Скачать Aurora Client», которая ведёт на страницу мода (`AURORA_PAGE` в `defaults.js`). Отключается в настройках.
- **Новости** Aurora и Minecraft: Java Edition, **русский и английский** интерфейс, выбор памяти с рекомендацией под ваш ПК.

## Установка

Запустите `AuroraLauncher-Setup-1.0.0.exe` и выберите папку. Windows SmartScreen может предупредить о неизвестном издателе, потому что установщик не подписан сертификатом: «Подробнее» → «Выполнить в любом случае».

Игра, Java и установки хранятся в `%APPDATA%\.aurora`:

```
.aurora
├── launcher.json      настройки лаунчера, установки, серверы
├── accounts.json      аккаунты (токены Microsoft зашифрованы)
├── skins/             скины офлайн-аккаунтов
├── icons/             свои иконки установок и файлы иконок ярлыков
├── versions/          файлы версий и клиент игры
├── libraries/         библиотеки
├── assets/            звуки, языки, текстуры
├── runtime/           Java от Mojang
├── instances/aurora/  папка игры установки «Aurora»: моды, миры, настройки, скриншоты
└── logs/              логи лаунчера и последних запусков игры
```

Первый запуск скачивает около 700 МБ.

### Вход через Microsoft

Mojang пускает в Minecraft только одобренные приложения, поэтому для входа с лицензией нужен **Client ID** приложения Azure. Его один раз вводят в «Настройках» или при первом добавлении аккаунта Microsoft:

1. Зарегистрируйте приложение на [portal.azure.com](https://portal.azure.com): «Personal Microsoft accounts», в разделе Authentication включите «Allow public client flows».
2. Подайте заявку Mojang на доступ к API Minecraft: [aka.ms/mce-reviewappid](https://aka.ms/mce-reviewappid).
3. Вставьте Application (client) ID в лаунчер.

Офлайн-аккаунты работают без этого.

## Разработка

Нужны Node.js 22+ и Python 3 с Pillow (только для иконки).

```bash
npm install
npm start
```

В режиме разработки лаунчер берёт мод Aurora прямо из `../build/libs` (соберите его через `gradlew build`), открывает DevTools по Ctrl+Shift+I и перезагружается по F5.

Сборка установщика:

```bash
npm run dist
```

Проект мода на Modrinth задан в `src/main/defaults.js` (`AURORA_MODRINTH`), приложение Discord — там же (`DISCORD_APP_ID`). Скрипт кладёт свежий `aurora-*.jar` из `../build/libs` в `resources/mods` и собирает `dist/AuroraLauncher-Setup-<версия>.exe` через electron-builder. Иконку перерисовывает `npm run icon`.

Служебные скрипты:

- `node scripts/smoke.js [--launch]` ставит установку Aurora без интерфейса и (с `--launch`) запускает игру офлайн-аккаунтом;
- `AURORA_SCRIPT=scripts/shots.js AURORA_HIDDEN=1 npx electron .` рисует окно вне экрана и сохраняет снимки всех страниц в `shots/` (план задаёт `AURORA_PLAN`).
- `trailer/` собирает трейлер лаунчера: съёмка интерфейса, голос, музыка и монтаж из кода (см. [`trailer/README.md`](trailer/README.md)).


Ярлык запускает `AuroraLauncher.exe --launch <id установки>`. Такой запуск не открывает главное окно: лаунчер проверяет файлы, запускает игру и закрывается после выхода из неё. Если лаунчер уже открыт, команда передаётся ему.

Интерфейс работает в песочнице (contextIsolation, sandbox, строгий CSP) и говорит с системой только через `preload.js`. Внешние ссылки открываются в браузере.
